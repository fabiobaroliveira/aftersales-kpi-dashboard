# 🚗 Dashboard de KPIs de Aftersales

Projeto de portfólio de análise de dados no setor automotivo, simulando o pipeline completo de um Analista de Aftersales.

## 📋 Sobre o Projeto

Análise de uma rede fictícia de concessionárias brasileiras com 28.000 Ordens de Serviço no período de Janeiro/2023 a Dezembro/2024.

## 📊 KPIs Analisados

- **Receita Total:** R$ 31.80M
- **Margem Bruta de Peças:** 36.6%
- **Ticket Médio por OS:** R$ 1,236
- **CSAT Médio:** 4.21 / 5.0
- **Taxa de Recompra:** 17.9%
- **Taxa de Retrabalho:** 7.7%

## 🔍 Principais Insights

1. Crescimento 2023→2024: -0.3%
2. Região líder: Sudeste (R$ 10.35M)
3. Canal dominante: Dealer Oficial (47.9%)
4. 34 clientes com 1 visita — oportunidade de CRM
5. Menor CSAT: Recall (4.18/5.0)
